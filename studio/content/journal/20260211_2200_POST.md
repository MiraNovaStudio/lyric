Lyric development is back in full swing. The Lyric specification has been updated to the most recent version and is now available here: [Lyric Specification](https://lyric-lang.org/specification.html)

You may have noticed we also removed the Lyric page on the MiraNova Studios website.  All information about the project will now be hosted on [lyric-lang.org](https://lyric-lang.org).

Key updates in this version include class inheritance, class scoping for methods, built-in getopts, file I/O operators, and command pipelining.

We are getting close to being release-ready, and it now looks realistic that Lyric will ship in Q1, as originally planned.

If you are curious about what the license will look like, it is now posted [here](https://lyric-lang.org/license.html) on lyric-lang.org as well.

*— Michael (Aeonath)*
