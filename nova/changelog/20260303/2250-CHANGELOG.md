# Adhoc — Standard Library specification documentation — 20260303.2250

## Summary
Added full Standard Library section to the Lyric language specification at
`lyric-lang.org/content/specification.md`. Documents all 22 public functions
organized into 5 categories with signature tables and code examples. Updated
the Planned Development section to reflect that the stdlib now exists.

## Files Changed
- `../lyric-lang.org/content/specification.md` — Added new `## Standard Library` section with 5 subsections (Time & Sleep, Random, File System, Path Utilities, Environment), each with a function reference table and usage examples. Updated Planned Development to reflect stdlib existence.

## Reason

standard library" which was outdated. The stdlib (`import lyric`) has been
available and needs proper documentation in the language specification.
