# Lyric

Lyric is a statically-typed, interpreted programming language developed by MiraNova Studios.

## Installation

```bash
pip install lyric-lang
```

## Getting Started

Visit [lyric-lang.org](https://lyric-lang.org) for documentation, language reference, and examples.

## Usage

```bash
lyric run program.ly
```
